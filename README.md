This is my Screen Time Tracker app that I made to help me and my friends keep an eye on how much time we spend on our phones every day. The idea came to me because I noticed I was spending way too much time scrolling and not enough time studying, so I wanted to build something that would show me the truth about my phone habits. The app lets you log the time you spend on different apps or activities throughout the day, like social media, games, YouTube, studying, or anything else you want to track. You just pick a category, type how many minutes you used it, and the app saves it for that day. At the top of the screen you can see your total screen time for today, and there's also a summary of your most used category so you know which app is eating up most of your time. You can also look at your history for the past week or past month, so you can see if you're improving or getting worse. If you go over a daily limit that you set yourself, the app warns you with a red highlight so you know you need to slow down. Everything is saved on your phone so the app works offline and your data stays private, nobody else can see it.

The project is organized into a few files to keep things clean. The main file is App.js and it takes care of showing the main screen, loading the data from the database, and keeping track of which day or week you're looking at. Inside the database folder, database.js opens the SQLite database, creates the table for storing screen time entries, and has functions for adding a new entry, reading entries for a specific date or range, updating an entry, and deleting an entry. In the components folder, you'll find entryform.js which is the form where you pick a category and type in the minutes, entryitem.js which shows one single entry on the screen with its category, time, and a delete button, and summarycard.js which shows the total time and top category for the day. Then in the utils folder, timehelper.js has all the helper functions like formatting minutes into hours and minutes (like "1h 25m" instead of "85 minutes"), getting today's date, checking if you went over your limit, and grouping entries by day for the weekly view.

To run this project, you first need Node.js and the Expo CLI installed. After that, just run npm install to get all the dependencies. If you're using SafeAreaView from react-native-safe-area-context, you also need to install it with npx expo install react-native-safe-area-context and wrap your app root in a SafeAreaProvider. To start the app, type npx expo start and then press a for Android, i for iOS, or just scan the QR code using the Expo Go app on your phone. Once it's running, you can start logging your screen time by picking a category from the list (like Social Media, Games, YouTube, Study, or Other), typing the minutes, and tapping the Add button. To delete an entry you just tap the Delete button and confirm. To switch between today, this week, and this month, use the tabs at the top. To set your daily limit, go to the settings screen and type in how many minutes you want to allow yourself per day.

A few things I want to point out about how I built it. First, the app is local-first, meaning everything is stored in SQLite on your phone so you don't need any account or internet connection. Second, I used the array form when binding parameters to SQLite queries because it's clearer and safer. Third, all database stuff is kept inside database.js so the UI components never touch SQL directly, and all the business logic is in timehelper.js as pure functions. The validation makes sure that the minutes you type is a positive number and that the category is one of the allowed ones, so you can't accidentally save a negative time or a category that doesn't exist. When you enter something wrong, the app shows a small alert so you know what to fix. The time formatting is also handled nicely, so if you log 90 minutes, it shows up as "1h 30m" instead of "90 minutes" which is easier to read. One important thing to remember is that the helper file is named timehelper.js with lowercase and no "s" at the end. I actually made a mistake before where I wrote timeHelpers instead of timehelper in one of the imports, and the app crashed when I tried to save an entry because the form couldn't find the file. So if you're on Linux or building for Android, make sure the import path matches the filename exactly because those systems are case-sensitive.

If you want to make this app better in the future, here are some ideas I have. You could add notifications that pop up when you're getting close to your daily limit, or even block certain apps automatically (but that's really advanced). You could add a chart or graph so you can see your screen time visually instead of just numbers. You could add categories for specific apps like Instagram, TikTok, YouTube, and Facebook instead of just general categories. You could add a weekly report that gets emailed or saved somewhere. You could add the ability to set different limits for different days of the week, like more time on weekends and less on school days. You could add dark mode. And maybe someday, a friend feature so you and your friends can compare screen time (but that might be a bit too much pressure). If you run into problems, the most common one is the module not found error which happens when you import from timeHelpers instead of timehelper, so just check the import path if the form crashes. If the app is stuck on the loading screen, check the Metro logs for a database error in initDatabase. If your entries disappear after reloading, check that the SQLite file is not being cleared by a dev client cache wipe. Also if the times look weird, make sure you're using the formatMinutes function from timehelper and not trying to do the math yourself in the component. This project is made for learning purposes and also to help me be more mindful about my phone use, so feel free to change it and make it your own. I hope this helps you take control of your screen time like it helped me!
